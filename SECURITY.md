# Security Policy

## Supported versions
Version 6.0.1 is the supported production line. Older builds may remain usable offline but do not receive integrity or import-safety fixes.

## Private reporting
Use GitHub Private Vulnerability Reporting in the official repository. Include the affected version, reproduction steps, impact, and any proof-of-concept material. Please avoid publicly disclosing exploitable details before maintainers have reviewed the report.

Acknowledgment timing depends on maintainer availability; no fixed service-level guarantee is claimed.
