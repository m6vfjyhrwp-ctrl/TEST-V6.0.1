# Executive Summary — v6.0.1

This release restores the mobile More Map Actions control, adds centralized release identity, runtime SHA-256 integrity monitoring, safer JSON imports, a restrictive GitHub Pages-compatible CSP, hardened same-origin offline caching, repository security templates, and release-signing preparation. Existing marker IDs, database version 9, user schema 3, and storage key `acbf-companion-m3` are preserved. Client-side integrity checks detect change; they do not prevent forks or determined modification.
