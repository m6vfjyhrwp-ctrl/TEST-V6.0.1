# Canonical Database Report — v5.1.0

## Scope

The v5.0 baseline contains 104 records across nine existing type identifiers. No new category was introduced. Existing record IDs and content coordinates were preserved.

## Reconciliation findings

- The 35 land-location records plus 7 underwater wrecks and 4 smuggler dens equal the documented 46 named location trackers.
- The fort category contains 11 records, matching the adopted baseline.
- Underwater wrecks contain 7 records, matching the adopted baseline.
- Ultimate Plans contain 12 records, matching the adopted baseline.
- Legendary encounters contain four map markers; the northeast marker represents two ships, yielding five individual legendary ships.
- The treasure dataset contains 26 standard/restored map treasures plus three time-limited/community event chests. Blackbeard’s Treasure is represented separately as an existing side-quest record.

No unsupported claim is made about categories absent from the app.
